# Changelog

## 0.1.0
- Initial Python package skeleton `fullswof_oil`.
- Added finite-volume solver with CFL control for shallow-layer oil flow.
- Added Rusanov flux module and friction closures (Manning/Darcy–Weisbach).
- Added simplified infiltration model and source-term coupling.
- Added runnable 1000 s example with plotting and output export.
- Added tests for mass conservation and CFL stability behavior.
